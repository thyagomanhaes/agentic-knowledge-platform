# agentic-knowledge-platform
Agentic Knowledge Platform — Multimodal RAG + GraphRAG on GCP

Build a production-grade data platform that ingests structured and unstructured enterprise data, transforms it into a unified knowledge layer composed of a data warehouse, vector database and knowledge graph, and exposes that knowledge to autonomous AI agents through APIs.

- FastAPI
- Pydantic
- SQLAlchemy
